# AltBlack OSINT & Recon Suite v40.0

Framework CLI sviluppato in Python per attività di OSINT, analisi di rete e profilazione target. Progettato con interfaccia modulare a colonne ed effetto Matrix integrato per l'esecuzione in ambienti terminale.

## 🚀 Requisiti

- **Python 3.8+**
- **Git**
